# Security policy

## Supported version

The current `main` branch is the only supported version.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting flow from the repository's
**Security** tab. Include the affected route or file, reproduction steps,
impact, and any suggested mitigation.

Do not disclose a vulnerability in a public issue before it has been reviewed.
Do not include credentials, personal information, or unrelated private data in
a report.
